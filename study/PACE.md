# Sampling pace note (4 November 2026)

The first sampling run went from 09:55 to 12:18 UTC (2.4 hours, stopped by a container restart, resumed at 15:08 UTC from progress.json) and only reached the first stratum, Claude Code in TypeScript, so every rate below comes from that one stratum and the others are not yet observed: it accepted 33 PRs out of 1,604 candidates checked (2.1 percent), about 14 accepted PRs per hour, with no 403 or 429 rate limit incidents. Of the 1,571 rejected candidates, 1,507 (95.9 percent) were in repositories under 100 stars, 37 (2.4 percent) had no agent marker in the body, 14 (0.9 percent) had changed lines outside 20 to 2,000, and 13 (0.8 percent) touched no test file; the sampler has no licence filter, so no candidate was rejected for licence. Almost every candidate costs one paced repository search call (8 seconds) for the star check, which is what sets the pace. At the observed rate the full 650 PR sample needs about 45 more hours, though the Devin, Cursor and Codex strata may sit in larger repositories and go faster, and the human baseline reuses cached repository data. Two options for the maintainer: (1) keep the design and let sampling run over about two days with the pacing unchanged; or (2) cut to 60 PRs per agent (20 per language) and 100 humans, 400 PRs in all, which at the same rate needs roughly 26 more hours and widens the interval on a 50 percent share from about 10 to about 12 percentage points either side per agent cohort. Option 2 only needs `--per-agent 60 --humans 100` on the next `pnpm study:sample`; PRs already accepted beyond a new target stay in the sample.

Update at 19:05 UTC: after about 6.3 hours of active sampling (09:55 to 12:18 and 15:08 to 19:05 UTC) the sample holds 108 PRs, about 17 accepted per hour overall. Claude Code is complete at 100 (TypeScript 34, Python 33, Java 33); Python took about 2.9 hours for 33 and Java about 0.6 hours for 33. Copilot TypeScript reached 8 in its first 20 minutes. Across 4,747 rejected candidates, 4,393 (92.5 percent) were in repositories under 100 stars, 167 touched no test file, 112 had changed lines outside 20 to 2,000, 63 had no agent marker, 8 repositories were not found by search and 4 had no merge base. There were no 403 or 429 incidents; one proxy connection reset at 17:47 UTC stopped the run, so `lib.ts` now retries connection resets with the same backoff and pacing. At 17 per hour the remaining 542 PRs need about 32 more hours, which supports the same two options as above.
