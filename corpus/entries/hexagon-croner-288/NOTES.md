# Hexagon/croner#288

Agent co-authored PR (Copilot co-author trailer) adding OCPS 1.0 to 1.4 compliance suites. Four of the new tests named for specific behaviour (wildcard matches all values, comma plus range, range plus step, nicknames not combinable) only assert that a run or instance is not null, so they prove the parser ran but not what it scheduled; a later PR in the same repository replaced several such checks. These four are labelled tp. The engine also reports O002 low on about 27 other new tests: some are acceptance tests where a non null check is the intent, and many assert real boolean conditions through assert(expr), which the TypeScript front end classes as truthiness only; those are left unlabelled as informational. Stresses O002 on node:assert style assert(x !== null).
